# Audio Format Converter

Batch converts .wav audio files to compressed formats for 
game engine delivery.

## Supported output formats

- .opus
- .ogg  
- .m4a

## Why I built it

Game engines require compressed audio formats. This is the first tool I built and
wanted to see if I can build something simple that could also be helpful.

## Requirements

- Python 3.x
